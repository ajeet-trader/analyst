Data Storage

All your data is stored locally on your computer:

  • signals.db - SQLite database with all signals and results
  • journal/archives/ - Chart screenshots for each trade
  • cache/ - Temporary screenshots (auto-cleared)

Maintenance Options (Settings Page)

⚠️ Delete Old Data (90+ days)

Removes signals older than 90 days to save space. Cannot be undone!

☢️ Reset Database

Deletes ALL signals, results, and journal entries. Use only if starting fresh!

Requires double confirmation to prevent accidents.

Backup Recommendation

Before resetting, manually copy these files:

  • signals.db
  • journal/ folder

❌ "No AI providers configured"

Solution:

  1. Copy .env.example to .env
  2. Add at least ONE API key (Groq, HuggingFace, or Together AI - all FREE)
  3. Restart python main.py

Get keys: Groq | HuggingFace

❌ Desktop notifications not showing

Solution:

  1. Windows Settings → System → Notifications
  2. Enable notifications for Python
  3. Check dashboard/config.py - NOTIFICATIONS['desktop_enabled'] = True

❌ Signal rejected by strategy

This is normal! Your active strategy filtered the signal.

Reasons:

  • Confidence too low for strategy (e.g., 75% but Conservative needs 80%+)
  • Wrong expiry (e.g., 5m but Scalping only allows 1-2m)
  • No patterns detected (some strategies require patterns)

Fix: Switch to a less strict strategy in Settings, or wait for better signals.

❌ AI always suggests 1m expiry

Solution: Capture higher timeframes!

If you want 5m expiry, capture: 5m, 15m, 30m (not 1m, 2m, 5m)

AI uses the middle/dominant timeframe for expiry calculation.

❌ Charts not visible on dashboard

Solution:

  1. Check Flask server is running
  2. Verify cache folder has images
  3. Refresh browser (Ctrl+F5)
  4. Check browser console for errors
